# Advent of Code

My solutions to [Advent of Code](https://adventofcode.com/), optimised for one
thing only: raw execution speed.

These are not reference solutions. The code is not meant to be idiomatic,
readable, portable or "the correct way" to solve a puzzle. Most solutions trade
clarity for speed on purpose.

I use each puzzle to apply ideas from mathematics, algorithms and data
structures, and information theory: closed forms instead of simulation,
bit-level parallelism and SIMD, exploiting the structure of the input. Some
solutions rely on properties of my own input and may not work on others.

Each day's folder has a write-up (`Advent of Code YYYY Day N Solution.pdf`) that
explains the problem analysis, the algorithm and the optimisations.
